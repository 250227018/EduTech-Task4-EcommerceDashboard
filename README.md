
# E-commerce Sales Dashboard - Task 4

## Tool Used
Power BI Desktop

## Dataset
Sample Superstore Dataset (Kaggle)
Link: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Charts Created
- Bar Chart: Sum of Sales by Category
- Line Chart: Sum of Sales by Order Date
- Pie Chart: Sum of Sales by Segment

## Insights
- Technology category has the highest sales
- Consumer segment contributes the most (50.56%) to total sales
- Sales were highest in early 2014 and show a declining trend over time

## Interview Questions
**Q: Best chart for trends?**
A: Line chart, as it clearly shows changes over time.

**Q: Dashboard vs Report?**
A: A dashboard is interactive and shows real-time key metrics in one view, while a report is detailed and static, used for in-depth analysis.
